  3. Open your browser to http://localhost:8080
Always use the (2) folder — it has the working keys and all features. Don't double-click an HTML file; the app must be opened through the running server at localhost:8080.

Known issues — expected behavior, not bugs

Image generation is slow / may time out. The free image service is currently down and there's no OpenAI key, so the app uses a slow local fallback. Tests C11 and C12 may hang or fail — this is the one known gap. Everything that uses an existing image (posting, documents) still works. Fix: add an OpenAI key or enable the instant local renderer.
If chat doesn't reply at all: you're likely running the wrong folder. Stop the server, make sure you're in the (2) folder, and run php spark serve again. The (2) folder has the valid API key and Facebook credentials.

How to report results

For anything that fails, note: the Test ID (e.g. C2), what you typed, and what you saw (the exact error or wrong behavior). A screenshot helps. Send that list back and it can be fixed quickly.
