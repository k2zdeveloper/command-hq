Connecting a Facebook Page

The exact, repeatable steps — use this for each company's real Page

This is the path that actually worked, with the snags we hit clearly marked so you can avoid them. Total time once you know it: ~10 minutes per Page.

The goal: get two things into the system —
  1. Your Page ID
  2. A permanent Page Access Token (never expires)
With those, the daily report reads real Facebook numbers and the system can auto-post — forever, no refreshing.

The 4 permissions you'll need every time

These let the system read your stats and post for you (read-only for reports; posting is optional):

pages_show_list pages_read_engagement read_insights pages_manage_posts

Part A — Create the app (once for the whole business)

You only do Part A one time. For additional Pages later, you can reuse the same app and jump to Part B.

  1. 1Create the app. Go to developers.facebook.com → My Apps → Create App. App type: Business. Name it (we used PN-Automation).
  2. 2Pick the use case. On "What do you want your app to do?", choose "Manage everything on your Page."
    The "Other" option is being removed by Meta — don't use it. "Manage everything on your Page" is the right one; it covers both reading stats and posting.
  3. 3Skip the business portfolio prompt. When asked to connect a verified business portfolio, choose "add later". It's fine — we only touch your own Page, so verification isn't required.
  4. 4Add the 4 permissions to the use case. In the app's left sidebar → Use cases → open "Manage everything on your Page" → Customize → click Add next to each of the four permissions listed above.
    At first only pages_show_list was available in the Graph API Explorer. The fix is exactly this step — permissions must be added to the use case here before they show up anywhere else.

Part B — Put the Page in your Business Portfolio

  1. 5Open Business Settings. Go to business.facebook.com → Settings (gear icon).
  2. 6Confirm the Page is there. Left menu → Accounts → Pages. Your Page should be listed (ours was "Upload Automation"). If it isn't, click Add → Add a Page and connect it.
    This was the real blocker. The token kept showing zero Pages because the Page wasn't surfacing. A Page owned by a Business Portfolio must be (a) listed here and (b) assigned to a system user — a regular personal token won't see it.
  3. 7Note the Page name. You'll confirm it later. (We never had to copy the ID by hand — the system fetches it from the token.)

Part C — Create a System User (the permanent, no-expiry key)

A "System User" is a robot account for automation. Its token never expires — perfect for a daily report.

  1. 8Create it. Business Settings → Users → System users → Add. Name it Automation Bot.
    Role Admin was blocked ("maximum 1 admin system user"). The fix: set the role to Employee instead — it works perfectly for reading and posting to a Page.
  2. 9Assign the Page to it. Select Automation Bot → Assign assets → Pages → pick your Page → turn on Full control → Save.
  3. 10Assign the App to it. Same screen → Assign assets → Apps → pick your app → Full control → Save.
    Both the Page and the App must be assigned to the system user. Assigning only one is why early attempts failed.
  4. 11Generate the permanent token. With Automation Bot selected → Generate new token → choose your app → Token expiration: Never → tick the 4 permissions → Generate.
    Token expiration = Never is the magic setting. This is what makes it zero-maintenance — the token never has to be refreshed.
  5. 12Copy the token and send it to the team (or paste into .env). That's it — the system fetches the Page ID from the token and saves both:
    facebook.pageId         = '988324637694167'
    facebook.pageAccessToken = 'EAAZ...permanent token...'
Done. The next daily report automatically includes that Page's real followers and post engagement — and it never breaks, because the token never expires.

To add the REAL company Pages later

For Positive Nation, K2Z Digital, Zengit, and A2Z Wellness, repeat only Parts B & C for each Page (the app from Part A is reused):

  1. Add the company's Page to the Business Portfolio (Step 6).
  2. Assign that Page to Automation Bot with Full control (Step 9).
  3. Generate a fresh Never-expiry token for it (Step 11), or send the team the Page name — one token per Page.

Then we map one Page to each company so every report section shows that company's own numbers.
