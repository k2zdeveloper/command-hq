Connecting Facebook for Daily Reports

A step-by-step, non-technical guide to switch on real Facebook numbers (followers, reach, post engagement) in your daily board report.

You don't need this to start. The daily report already works and emails you every day using live website checks and AI analysis. This guide only adds real Facebook metrics on top. Do it whenever you're ready.

What you're getting

Facebook calls this a Page Access Token — think of it as a special key that lets our system read your Page's numbers. Once you paste this key into the system, the daily report automatically starts including real Facebook follower counts and post performance. No code changes needed.

The steps

  1. Open Meta for Developers. Go to developers.facebook.com and log in. Click My Apps → Create App. Choose type "Business", give it any name (e.g. "Mosbat Reporting"), and create it.
  2. Open the Graph API Explorer. Go to developers.facebook.com/tools/explorer. In the top-right, select the app you just created.
  3. Choose your Page. Click the "User or Page" dropdown → Get Page Access Token → pick your Page and approve the popup.
  4. Add the read permissions. Click "Add a Permission" and tick these three:
    pages_read_engagement · pages_show_list · read_insights
    Then click "Generate Access Token" and approve. A long code appears in the "Access Token" box — that's your key.
  5. Make the key long-lived (important). The key from step 4 expires in about an hour. To get one that lasts ~60 days, open the Access Token Debugger at developers.facebook.com/tools/debug/accesstoken, paste your key, click Debug, then click "Extend Access Token" at the bottom. Copy the new, longer-lasting key.
  6. Find your Page ID. On your Facebook Page, go to Settings → About and scroll to "Page ID" (a long number). Or it's shown in the Graph API Explorer response.
  7. Give both to us. Send the team the Page ID and the long-lived token, or paste them into the system's .env file like this:
    facebook.pageId         = '1234567890'
    facebook.pageAccessToken = 'EAAG...your-long-token...'
That's it. The very next daily report will automatically include your real Facebook followers and recent post performance. Nothing else to do.

Good to know

  • Tokens expire. The long-lived key lasts ~60 days. When it expires, the report will simply say "Facebook not connected" again, and you repeat steps 4–7. (A permanent "System User" token is possible later for zero maintenance — ask the team.)
  • Instagram too. If your Instagram is a Business account linked to this Page, the same app can later pull Instagram numbers — a small add-on when you want it.
  • It's read-only and safe. These permissions only let us read your numbers for the report. Keep the token private — treat it like a password.
If you get stuck at any step, send the team a screenshot of where you are — the most common snag is the permissions in step 4 or extending the token in step 5.
